# Conectivos Lógicos e Tabela Verdade

Projeto em JavaScript que demonstra os conectivos lógicos e a construção de tabelas
verdade, com foco nos fundamentos da lógica de programação.

## Conceitos abordados

- Proposição lógica
- AND (&&)
- OR (||)
- NOT (!)
- Tabela verdade
- Expressões lógicas combinadas

## Exemplo prático

O projeto inclui um exemplo simples de verificação de acesso, simulando uma
situação comum em sistemas:

```js
const usuarioLogado = true;
const temPermissao = false;

const podeAcessar = usuarioLogado && temPermissao;
